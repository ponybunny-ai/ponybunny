# LLM 调用时 token 记录数据错误

## 现状
1. 使用 `pb models test` 发起模型测试对话时，返回的 `metadata` 中 `inputTokens` / `outputTokens` 存在统计偏差。
2. 当前观测到的样例中，CLI 输出为 `inputTokens: 0`、`outputTokens: 32`，与后台观测值（`inputTokens: 7`、`outputTokens: 25`）不一致。

## 复现步骤
1. 执行：`pb models test CPA.gpt-5.1`。
2. 输入一条简单消息（例如：`hello`）。
3. 观察 CLI 返回的 `metadata` 字段，重点关注 `inputTokens`、`outputTokens`、`totalTokens`。
4. 对比后台同一请求的 token 统计数据。

## 期望结果
1. `pb models test` 输出的 `metadata.inputTokens` / `metadata.outputTokens` 与 provider 实际返回值一致。
2. 系统在执行 LLM 请求时，能够稳定记录正确的 token metadata（含输入、输出、总量和成本估算）。

## 验收标准
- [ ] `pb models test` 单轮与多轮会话中，CLI token 数据与后台记录一致。
- [ ] `inputTokens + outputTokens = totalTokens`（在 provider 返回该口径时成立）。
- [ ] 不同 provider 下 token 字段映射逻辑一致，不出现固定为 0 或异常放大的情况。
- [ ] 回归后 `estimatedCostUsd` 随 token 变化而合理变化。
