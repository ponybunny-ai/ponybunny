# UnifiedProvider 在调用llm model的时候对model name的处理错误

## model name的解析逻辑

- llm-config 中配置的model的格式是 `<provider>.<model_name>` ， 举个例子： openai.gpt-5.2 代表需要到 llm-config的models配置里寻找provider是openai的分支然后再找gpt-5.2模型。
- 整个系统里都遵循这个规则做model的配置和解析使用的。
