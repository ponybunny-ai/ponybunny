# TUI 选择 model 的交互异常

## 现状
1. 主 TUI 当前通过 `/models` 打开 model selector（`ctrl-m` 已移除）。
2. 在 model selector 打开后进行鼠标点击，会把终端鼠标控制序列写入输入框，随后鼠标交互失效（如右下角 Dashboard/Tasks 等 tab 不再响应切换），通常只能重启 TUI 恢复。

## 复现步骤
1. 启动主 TUI：`pb`。
2. 输入 `/models` 打开 model selector。
3. 在 selector 中使用鼠标点击（例如点击输入框或列表项）。
4. 观察输入框出现鼠标控制序列字符串（如 `\u001b[<...m/M` 片段），并继续尝试点击底部 tab 区域。
5. 观察 tab 点击不再触发视图切换，鼠标交互进入失效状态。

## 期望结果
1. `/models` 可稳定打开 selector（键盘与鼠标操作不冲突）。
2. 鼠标点击不会向输入框注入控制序列字符串。
3. model selector 使用期间与关闭后，Dashboard/Tasks 等 tab 鼠标点击应持续可用。

## 验收标准
- [ ] `/models` 能稳定打开 model selector。
- [ ] selector 期间不会出现鼠标控制序列串进入输入框。
- [ ] selector 操作后，tab 区域鼠标点击仍可正常切换视图。
