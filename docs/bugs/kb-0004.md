## 当前界面存在的问题

1. VI的编辑模式，会让非专业用户非常疑惑，很难理解命令模式和输入模式的不同与切换方法，显著拉高了系统的使用门槛。 需要改为在任何视图下的光标都默认聚焦在底部的输入框，用户不需要通过按 i 或者 / 按键来进入输入模式，再按esc键退出输入模式。
2. 将当前的命令状态下的1、2、3、4、5按键切换视图的功能改为ctrl-1，ctrl-2，ctrl-3，ctrl-4，ctrl-5。 通过组合键的方式做视图切换。 去掉Tab切换视图的功能。 当前的 Help 视图通过命令调取，不再通过快捷键和tab切换。
3. 页面内容的布局做调整。 

    3.1 第二行移动到footer，靠右侧对齐显示。 当前视图对应的文字使用高亮背景色做反色显示。
        - 当前
```
 [1] Dashboard  [2] Tasks  [3] Goals  [4] Events  [5] Help                                                                                                 Tab to switch
```
        - 更改为
```
Dashboard [Ctrl-1] Tasks [Ctrl-2] Goals [Ctrl-3] Events [Ctrl-4] 
```

    3.2 当前footer的内容和触发的功能去掉。 替换为当前系统使用的Agent、model、provider等信息。 （需要后台提供相应的数据接口和api接口来支持）

    - 当前
```
  / or i to type │ Tab switch view │ Ctrl+N new goal │ Ctrl+E escalations │ Ctrl+R refresh
```

    - 更改为
```
  guard │ openai.gpt-5.2 <variant> │ ctrl-t variants tab agents ctrl-p commands 
```
其中： 
    - 当检测到当前选择的模型支持不同的variants时，显示 `ctrl-t variants` 并且当用户按下 ctrl-t 时循环切换支持的（llm-config中配置的）variants，并在 openai.gpt-5.2 <variant> 里面的variant里显示当前切换到的内容。
    - 当用户按tab键，系统在后天已加载的并且可用的agents里做轮换（需要后台同时提供相应的接口支持）
    - 当用户按 ctrl-p 键时，弹出一个对话框，在里面可以像vscode的command-shift-p呼叫出来的对话框一样，上面提供搜索命令的功能，下面是滚动显示的当前系统支持的全部功能和命令的清单，上下键选择，回车键确认执行。

    3.3 更改底部的输入框，加一个背景色（我可以方便的配置）。这个默认的输入框为2行，第1行作为输入框，第二行作为固定的信息输出框（上面3.2的内容）。
